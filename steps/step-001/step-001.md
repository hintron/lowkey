# Task

Write a [`Hello, world`](https://en.wikipedia.org/wiki/Hello,_world) program in the language of your choice. Then, create a test runner program that will invoke your program and check it against the expected output file in the `tests` folder.


# Hints

NOTE: View this on a web browser in GitHub or in a markdown viewer to avoid spoilers!

<details>
<summary>Show Hint 1</summary>

There are a few ways to do this. You can either write a built-in test (if your language has that kind of thing) and call your main function from that. Or, you can write bash or shell scripts on Linux/macOS, or Batch or PowerShell scripts on Windows.
